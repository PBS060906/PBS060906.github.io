# 动态规划

动态规划 = **把原问题拆成重叠子问题，每个子问题只求解一次**。适用条件：最优子结构 + 重叠子问题。它不是某个具体算法，而是一套"用空间换时间、自底向上填表"的思维方式——暴力搜索之所以慢，正败在相同的子问题被反复重算。

## 解题框架

1. **定义状态**：`dp[i]` 表示什么（最关键的一步），定义错了后面全部推倒重来；
2. **状态转移方程**：`dp[i]` 如何由更小的子问题推出；
3. **初始化与边界**：递推的起点，通常是最小子问题的答案；
4. **遍历顺序**：保证计算 `dp[i]` 时依赖项已就绪；
5. **空间优化**：滚动数组压缩维度。

```mermaid
flowchart LR
    A[暴力递归] -->|子问题重叠| B[记忆化搜索]
    B -->|改写为循环| C[递推填表]
    C -->|只依赖上一维| D[滚动数组]
```

## 线性 DP

### 最长上升子序列（LIS）

**状态定义**：`dp[i]` 表示以 `a[i]` 结尾的最长上升子序列长度。

$$
dp[i] = \max_{j<i,\ a_j < a_i} (dp[j]) + 1
$$

```cpp
for (int i = 0; i < n; i++) {
    dp[i] = 1;  // 至少包含自身
    for (int j = 0; j < i; j++)
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);  // 接到更长的前驱后面
}
```

时间复杂度 $O(n^2)$。贪心 + 二分可将复杂度优化到 $O(n \log n)$：维护数组 `tails`，`tails[k]` 表示"长度为 k+1 的上升子序列的最小结尾"，每个新元素二分找插入位置，替换或追加。

```cpp
vector<int> tails;  // tails 始终有序，但未必是一条真实的 LIS
for (int i = 0; i < n; i++) {
    auto it = lower_bound(tails.begin(), tails.end(), a[i]);
    if (it == tails.end()) tails.push_back(a[i]);  // 连最小结尾都放不下 → LIS 变长
    else *it = a[i];                               // 用更小的值替换，给后续元素留机会
}
// tails.size() 即 LIS 长度
```

### 最长公共子序列（LCS）

**状态定义**：`dp[i][j]` 表示 `a` 的前 i 个字符与 `b` 的前 j 个字符的 LCS 长度。

$$
dp[i][j] = \begin{cases} dp[i-1][j-1] + 1, & a_i = b_j \\ \max(dp[i-1][j],\ dp[i][j-1]), & a_i \neq b_j \end{cases}
$$

边界 `dp[0][j] = dp[i][0] = 0`（空串与任何串的 LCS 为 0），时间与空间均为 $O(nm)$。若需输出具体方案，从 `dp[n][m]` 沿转移来源回溯。

## 背包 DP

**状态定义**：`dp[j]` 表示背包容量为 j 时能取得的最大价值。

```cpp
// 0-1 背包：n 件物品，容量 m，第 i 件重 w[i]、价值 v[i]
for (int i = 0; i < n; i++)
    for (int j = m; j >= w[i]; j--)  // 倒序：保证每件物品只被选中一次
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

| 模型 | 转移方程 | 要点 |
| ---- | -------- | ---- |
| 0-1 背包 | `dp[j] = max(dp[j], dp[j-w]+v)`，**j 倒序** | 每件至多选一次 |
| 完全背包 | 同上，**j 正序** | 每件可重复选 |
| 分组背包 | 枚举每组"选哪一件" | 组内至多选一件 |

正序与倒序的本质区别：倒序保证 `dp[j-w]` 还是上一轮（未考虑当前物品）的值；正序则允许"本轮更新过的 `dp[j-w]` 再被使用"，等价于物品可重复选。

## 区间 DP：石子合并

**状态定义**：`dp[l][r]` 为合并区间 `[l, r]` 内所有石子堆的最小代价。最后一次合并一定是"相邻两大堆"，由此枚举分割点 k。

```cpp
// dp[l][r] = 合并区间 [l, r] 的最小代价
for (int len = 2; len <= n; len++)
    for (int l = 0, r = l + len - 1; r < n; l++, r++) {
        dp[l][r] = INF;
        for (int k = l; k < r; k++)
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + sum(l, r));  // sum 为区间和，前缀和 O(1) 取
    }
```

区间 DP 的遍历顺序固定为**按区间长度从短到长**，复杂度 $O(n^3)$。矩阵链乘法、戳气球同属此模型。

## 树形 DP

**例：没有上司的舞会**——选一批员工使快乐值总和最大，直接上下级不能同时选。

**状态定义**：`dp[u][0/1]` 表示以 u 为根的子树中，u 不选 / 选 时的最大快乐值。

```cpp
void dfs(int u) {
    dp[u][0] = 0;
    dp[u][1] = w[u];  // 选 u，先计入自身快乐值
    for (int v : children[u]) {
        dfs(v);
        dp[u][0] += max(dp[v][0], dp[v][1]);  // u 不选，下属可选可不选
        dp[u][1] += dp[v][0];                 // u 选了，直接下属都不能选
    }
}
```

树形 DP 的计算顺序即树的**后序遍历**：先算完子树，再合并到父节点。

## 记忆化搜索

用递归 + 缓存表写 DP：算过的状态存进 `memo`，再次遇到直接返回。它与递推完全等价，优点是转移写法直观、自动跳过无效状态；缺点是递归常数大、可能爆栈。先想清楚转移关系，再决定用搜索还是填表。

```cpp
vector<int> memo(n, -1);  // -1 表示尚未计算

int solve(int i) {
    if (i <= 1) return i;                  // 边界直接返回
    int& res = memo[i];
    if (res != -1) return res;             // 缓存命中，不再重算
    return res = solve(i - 1) + solve(i - 2);  // 计算并写入缓存
}
```

注意 `int& res` 是引用：修改 `res` 就是修改 `memo[i]`，省去一次重复书写。

## 常见优化手段

- **滚动数组**：`dp[i]` 只依赖 `dp[i-1]` 时压掉一维；
- **前缀和优化**：转移是区间求和时预处理前缀；
- **单调队列优化**：滑动窗口最值转移，模板见 [代码模板](../templates.md#单调队列)，可将线性 DP 从 $O(n^2)$ 降到 $O(n)$；
- **二进制状态压缩**：集合类问题用位掩码表示"选没选"，$O(2^n)$ 状态换取可行性。

## 经典模型速查

| 模型 | 状态定义关键词 | 典型例题 |
| ---- | -------------- | -------- |
| 线性 DP | 以 i 结尾 / 前 i 个 | LIS、LCS、最大子段和 |
| 背包 DP | 容量 j | 0-1 / 完全 / 分组背包 |
| 区间 DP | `dp[l][r]` | 石子合并、矩阵链乘 |
| 树形 DP | 以 u 为根的子树 | 没有上司的舞会 |
| 状压 DP | 位掩码集合 | 旅行商问题（TSP） |

!!! tip "检验标准"

    能对新手讲清楚"状态为什么这样定义、转移为什么正确"，才算真正掌握该模型。

## 小结

- 状态定义决定一切：先说清 `dp[i]`（或 `dp[i][j]`）的含义，再写方程；
- 0-1 背包倒序、完全背包正序，方向错了整个模型就错了；
- 区间 DP 按长度枚举，树形 DP 按后序遍历；
- 想不动就手推小样例：拿 n=3 把状态表算一遍，转移是否正确一目了然。
