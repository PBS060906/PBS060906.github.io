## 学习方法论

!!! tip "三遍学习法"

    1. **第一遍**：直接看题解，理解思路并手动模拟；
    2. **第二遍**：独立实现，与模板对照修正；
    3. **第三遍**：隔一周重做，追求一次通过。

## 复杂度速查

| 数据规模 $n$ | 可接受复杂度 |
| ------------ | ------------ |
| $\le 20$ | $O(2^n)$ 搜索 |
| $\le 500$ | $O(n^3)$ |
| $\le 10^4$ | $O(n^2)$ |
| $\le 10^6$ | $O(n \log n)$ |
| $\ge 10^7$ | $O(n)$ / $O(\log n)$ |
