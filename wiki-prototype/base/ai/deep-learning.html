深度学习

深度学习的核心闭环：前向算损失，反向传梯度，优化器更新参数。本页围绕这个闭环建立最小知识体系，全部概念都可用页末的 PyTorch 示例亲手验证。

从 MLP 说起

一个神经元 = 线性变换 + 非线性激活；神经元排成层、层与层全连接，就是多层感知机（MLP）。每一层做的事：

a(l) = σ(W(l)a(l−1) + b(l))

理论上，足够宽的单隐层网络已能近似任意连续函数（万能近似定理），但能近似不等于学得动——深层结构带来的层次化表达与参数效率才是实践中的关键。

前向与反向传播

前向传播把输入逐层变换成预测；反向传播用链式法则，把损失对每个参数的梯度从后往前逐层算出。以单层计算图为例：

输入 x→z = Wx + b→a = σ(z)→损失 L(a, y)

反向时箭头倒过来，每层只需"上游传来的梯度"乘以"本层的局部导数"：

∂L/∂W = ∂L/∂a · ∂a/∂z · ∂z/∂W

框架（如 PyTorch 的 autograd）会自动完成这一切——你只需写出前向计算，梯度自动可求。

激活函数对比

没有非线性激活，多层网络会塌缩成一层线性变换。常用激活函数速查：

激活函数公式优点坑
Sigmoid1 / (1 + e−z)输出 (0,1)，可解释为概率两端饱和 → 梯度消失；输出非零中心
Tanh(ez − e−z) / (ez + e−z)零中心，收敛快于 Sigmoid仍有饱和区
ReLUmax(0, z)计算极快，正区间梯度恒为 1死 ReLU：负区间梯度恒 0，神经元"装死"
GELUz · Φ(z)平滑非单调，Transformer 默认计算略贵，小模型收益有限

损失函数

  • MSE（均方误差）：回归默认，L = (1/n) Σ(ŷi − yi)2，对离群点敏感；
  • 交叉熵：分类默认，度量预测概率分布与真实标签的距离，梯度干净（p − y），配合 sigmoid / softmax 使用。

优化器演进

优化器一行直觉
SGD沿当前梯度小步走，简单，但方向易震荡
Momentum累积历史梯度当"惯性"，冲过小坑、抑制震荡
Adam给每个参数自适应学习率，新任务的默认首选
AdamWAdam + 解耦的权重衰减，Transformer 时代标配

正则化三件套

  • Dropout：训练时随机把一部分激活置零，逼网络不依赖个别神经元；评估时必须关闭（model.eval()）；
  • 权重衰减：在损失中加 λ‖w‖2，压制参数规模，得到更平滑的函数；
  • BatchNorm：把每层输入归一化到稳定分布，训练更快更稳，顺带带来轻微正则。

三者机制完全不同（去共适应 / 压参数 / 稳分布），可以组合使用，但不宜盲目堆叠。

训练循环：PyTorch 最小示例

五步口诀：zero_grad → forward → loss → backward → step。下面用两层全连接网络拟合带噪声的一维函数，可直接运行：

import torch
import torch.nn as nn

# 1. 数据：拟合 sin(x)，输入输出各一维
torch.manual_seed(0)
x = torch.linspace(-3, 3, 200).unsqueeze(1)       # 形状 (200, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)      # 叠加高斯噪声

# 2. 模型：两层网络（隐藏层 64 维）
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = nn.Sequential(
    nn.Linear(1, 64),
    nn.Tanh(),                                    # 非线性激活
    nn.Linear(64, 1),
).to(device)                                      # 模型搬到 GPU（若有）

# 3. 损失与优化器
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-2)

# 4. 训练循环：口诀 zero_grad → forward → loss → backward → step
for epoch in range(1000):
    pred = model(x.to(device))                    # 前向传播
    loss = loss_fn(pred, y.to(device))            # 计算损失
    optimizer.zero_grad()                         # 清空上一步的梯度
    loss.backward()                               # 反向传播求梯度
    optimizer.step()                              # 用梯度更新参数
    if (epoch + 1) % 200 == 0:
        print(f"epoch {epoch + 1:4d}, loss {loss.item():.4f}")

GPU 与 device

张量与模型必须位于同一设备才能计算：.to(device) 一行即可在 CPU / GPU 间切换，其余代码不变；忘记把输入数据一起 .to(device) 是最常见报错。

过拟合诊断：看 train / val 曲线

训练时同时记录训练集与验证集损失，两条曲线的相对走势就是诊断书：

现象诊断药方
train 降、val 升过拟合Dropout / 权重衰减 / 早停 / 扩充数据
两条都高欠拟合加深加宽 / 换激活 / 训练更久
两条都低、val 略高健康收敛正常，可继续打磨数据与超参

Tip · 每次实验只动一件事

调参时一次只改学习率、网络宽度或正则强度中的一个变量，并固定随机种子，否则曲线差异无法归因。
