关键概念

过拟合与欠拟合

  • 欠拟合：训练误差与测试误差都高 → 模型容量不足，增加特征或模型复杂度；
  • 过拟合：训练误差低而测试误差高 → 正则化、早停、数据增强、交叉验证。

偏差—方差权衡

Error = Bias2 + Variance + Noise

模型复杂度上升时，偏差下降、方差上升，最优点在中间。

线性回归

假设目标与特征近似线性：ŷ = wTx + b，训练目标是最小化均方误差：

minw,b Σi (wTxi + b − yi)2

两种求解视角

  • 正规方程（闭式解）：令梯度为零直接解出 w = (XTX)−1XTy，一步到位，但特征多时矩阵求逆又慢又不稳；
  • 梯度下降（迭代解）：沿负梯度方向小步更新 w ← w − η∇L。批量 GD 每步用全量数据（稳但慢），SGD 每步只用一个样本（快但有噪声）——深度学习走的都是后者的变体。
from sklearn.linear_model import LinearRegression, SGDRegressor

model = LinearRegression().fit(X, y)           # 正规方程：闭式解
sgd = SGDRegressor(max_iter=1000).fit(X, y)    # 梯度下降：迭代解

逻辑回归与交叉熵

把线性输出用 sigmoid 压到 (0,1) 当概率：p = σ(wTx + b)。分类的损失用交叉熵：

L = −Σi [yi log pi + (1 − yi) log(1 − pi)]

Question · 为什么分类不用 MSE？

两个原因：其一，MSE 配 sigmoid 是非凸函数，存在多个局部极小；其二，当预测错得离谱（y = 1 而 p ≈ 0）时，sigmoid 处于饱和区，MSE 的梯度反而趋近 0——"错得越狠学得越慢"。交叉熵的梯度恰好是 p − y：误差越大，更新越猛。

决策树与集成学习

  • Bagging / 随机森林：对训练集有放回采样出多份数据，各训一棵深树，最后投票平均，思路是降方差——多棵"见解不同"的树互相抵消各自的过拟合；随机森林再加特征随机子集，让树之间差异更大；
  • Boosting / XGBoost：串行训练小树，每棵专门拟合前面所有树的残差（梯度），思路是降偏差——一步步逼近正确答案；XGBoost 在此之上引入二阶梯度、正则项与列采样，长期霸榜表格数据。
场景首选模型理由
表格数据、样本中等、缺失多随机森林 / XGBoost对量纲、缺失、非线性天然鲁棒
关系近似线性、要解释系数线性 / 逻辑回归可解释、训练快、高维稀疏表现好
图像、语音、文本原始信号深度学习特征需要自动学习而非人工设计

特征工程

数值缩放

标准化 z = (x − μ) / σ 或 MinMax 压到 [0,1]。线性模型、KNN、神经网络对量纲敏感，必须缩放；树模型逐特征分裂，可不做。

类别编码

  • One-Hot：适合低基数无序类别（城市、性别），线性模型标配；
  • Target 编码：用类别对应的目标均值替换，适合高基数（用户 ID），但统计量只能来自训练集，否则直接泄漏。

缺失值策略

删行删列（缺得少且无关紧要）、中位数 / 众数填充（对离群点稳健）、追加"是否缺失"指示列（缺失本身有信息量）；树模型还可把缺失当作独立分支交给模型学。

泄漏防范

Warning · 训练集 fit，测试集只 transform

任何统计量（均值、方差、类别目标均值）都必须只在训练集上 fit，再应用到验证 / 测试集。"先全量归一化再划分数据"是新手最容易犯、也最难察觉的泄漏。

Question · 不平衡数据为何不看 Accuracy？

负样本占 99% 时，"无脑全预测负"就能拿到 99% 的 Accuracy，却一个正类也没抓到。欺诈检测、疾病筛查等场景应看 Recall、F1 或 PR 曲线。

回归指标

  • MAE：平均绝对误差，对离群点鲁棒；
  • MSE：平方惩罚，离群点主导优化方向；
  • R²：相对"只预测均值"这个基线解释了多少方差，可为负。

交叉验证

K-Fold 把数据分成 K 份，轮流用 1 份做验证、其余做训练，得到 K 个分数取均值——比单次划分稳得多：

from sklearn.model_selection import cross_val_score, StratifiedKFold

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
scores = cross_val_score(clf, X, y, cv=cv, scoring="f1_macro")
print(f"{scores.mean():.3f} ± {scores.std():.3f}")
  • 分类（尤其类别不平衡）→ StratifiedKFold：每折保持类别比例一致；
  • 回归 → 普通 KFold；
  • 时间序列 → TimeSeriesSplit：绝不能用未来数据训练过去。

最小工作示例

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

clf = LogisticRegression(max_iter=1000).fit(X_tr, y_tr)
print(accuracy_score(y_te, clf.predict(X_te)))  # ~0.97

Warning · 常见误区

评估指标要在测试集上看；把全量数据先归一化再划分会造成数据泄漏。

端到端 Pipeline 示例

把"填充 → 缩放 → 编码 → 模型"串成一个对象，交叉验证时每折各自重新 fit 预处理器，从机制上杜绝泄漏：

from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score, StratifiedKFold

num_cols = ["age", "income"]     # 数值列：中位数填充 + 标准化
cat_cols = ["city", "job"]       # 类别列：众数填充 + One-Hot

preprocess = ColumnTransformer([
    ("num", Pipeline([
        ("imp", SimpleImputer(strategy="median")),
        ("scale", StandardScaler()),
    ]), num_cols),
    ("cat", Pipeline([
        ("imp", SimpleImputer(strategy="most_frequent")),
        ("onehot", OneHotEncoder(handle_unknown="ignore")),
    ]), cat_cols),
])

pipe = Pipeline([
    ("prep", preprocess),
    ("clf", LogisticRegression(max_iter=1000)),
])

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
scores = cross_val_score(pipe, X, y, cv=cv, scoring="roc_auc")
print(f"AUC = {scores.mean():.3f} ± {scores.std():.3f}")

Tip · Pipeline 是工程习惯的分水岭

预处理散落在模型之外的脚本里，迟早会在某次换数据时悄悄泄漏；用 Pipeline 绑定后，保存、加载、上线部署都是同一个对象。
