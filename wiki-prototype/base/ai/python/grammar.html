语法基础

本节梳理 Python 最核心的语法要素，帮助读者快速建立语言的"骨架"认知。建议边读边在解释器里把每个片段敲一遍验证。

变量与类型

Python 是动态类型语言，变量无需声明类型：

x: int = 42              # 整数
y: float = 3.14          # 浮点数
s: str = "hello"         # 字符串
items: list[int] = [1, 2, 3]   # 列表
point: tuple[int, int] = (1, 2)  # 元组
cache: dict[str, int] = {"a": 1} # 字典

Note · 一切皆对象

Python 中数字、函数、类本身都是对象，变量只是对象的名字绑定，而非"盒子"。

控制流

for i in range(10):
    if i % 2 == 0:
        continue
    print(i, end=" ")

# 1 3 5 7 9

三元表达式与解包是高频用法：

parity = "even" if n % 2 == 0 else "odd"
a, b = b, a               # 交换
first, *rest = [1, 2, 3]  # first=1, rest=[2, 3]

函数

def fib(n: int) -> list[int]:
    """返回前 n 个斐波那契数。"""
    seq = [0, 1]
    for _ in range(n - 2):
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

参数传递的要点

  • 位置参数在前，关键字参数在后；
  • 默认参数避免使用可变对象；
# 反例：默认列表会在多次调用间共享
def append_to(item, bucket=[]): ...   # 危险

# 正确写法
def append_to(item, bucket=None):
    bucket = [] if bucket is None else bucket

面向对象速览

class Animal:
    def __init__(self, name: str):
        self.name = name

    def speak(self) -> str:
        raise NotImplementedError

class Dog(Animal):
    def speak(self) -> str:
        return f"{self.name}: 汪汪"

print(Dog("旺财").speak())  # 旺财: 汪汪

推导式与生成器

三种推导式

列表、字典、集合推导式是"过滤 + 变换"的一行写法，代替低效的"先建空容器再循环追加"：

nums = range(10)

# 列表推导式：变换 + 过滤
squares = [x * x for x in nums if x % 2 == 0]   # [0, 4, 16, 36, 64]

# 字典 / 集合推导式：只换外层括号
word = "mississippi"
counts = {ch: word.count(ch) for ch in set(word)}  # {'m': 1, 'i': 4, ...}
lengths = {len(w) for w in ["go", "py", "go"]}     # {2}

# 嵌套推导式：矩阵展平（最多两层，再多改普通循环）
matrix = [[1, 2], [3, 4]]
flat = [v for row in matrix for v in row]          # [1, 2, 3, 4]

生成器函数与 yield

函数体内出现 yield，它就变成生成器：每次 next() 执行到 yield 处暂停，交出一个值，下次从暂停处继续。

def fib():
    """无限斐波那契序列：用到哪个算哪个。"""
    a, b = 0, 1
    while True:
        yield a              # 函数在这里暂停
        a, b = b, a + b

gen = fib()
print([next(gen) for _ in range(8)])   # [0, 1, 1, 2, 3, 5, 8, 13]

# 生成器表达式：把列表推导式的 [] 换成 ()
total = sum(x * x for x in range(10**6))   # 不构造百万级的中间列表

惰性求值的优势

列表推导式"先全部算好"，生成器"用到才算"。处理大文件、无限序列、管道式数据流时，惰性求值把内存占用从 O(n) 降到 O(1)：

# 逐行筛出大日志中的错误行：无论文件多大，内存占用恒定
def error_lines(path: str):
    with open(path, encoding="utf-8") as f:
        for line in f:
            if "ERROR" in line:
                yield line.strip()

Warning · 生成器只能消费一次

遍历一遍后生成器就耗尽了，再 len() 或再 for 只会得到空结果；需要反复使用请先 list(gen) 落地。

异常处理

完整的 try 结构分四块：try 包住可能出错的代码，except 分支捕获具体异常，else 只在无异常时执行，finally 无论成败都执行。

import json

def load_config(path: str) -> dict:
    try:
        with open(path, encoding="utf-8") as f:
            data = json.load(f)
    except FileNotFoundError:
        print("配置不存在，使用默认值")
        return {}
    except json.JSONDecodeError as e:
        print(f"配置格式非法：{e}")
        return {}
    else:
        print("读取成功")          # 仅当 try 块无异常时执行
    finally:
        print("加载流程结束")       # 无论走哪个分支都执行，适合做清理
    return data

自定义异常

业务代码不要到处抛裸的 Exception，而是建立一层异常基类，调用方按类捕获：

class AppError(Exception):
    """业务异常基类：调用方只需捕获这一类。"""

class PaymentDeclined(AppError):
    def __init__(self, reason: str):
        super().__init__(f"支付被拒绝：{reason}")

def pay(amount: float) -> None:
    if amount <= 0:
        raise PaymentDeclined("金额必须为正")

try:
    pay(-1)
except AppError as e:            # 按基类捕获，未来新增子类无需改调用方
    print(e)

EAFP 风格

Python 社区推崇 EAFP（先做再兜底）而非 LBYL（先判断再访问）：

# LBYL：先判断再访问，判断与访问之间状态可能变化
if "discount" in config:
    rate = config["discount"]
else:
    rate = 1.0

# EAFP：直接做，出异常再兜底（Python 首选）
try:
    rate = config["discount"]
except KeyError:
    rate = 1.0

Warning · 捕获要具体

裸 except: 会把 KeyboardInterrupt、程序 bug 一并吞掉，线上排查时"无声消失"最致命。至少写 except Exception，并记录日志。

上下文管理器

with 的价值是确定性释放资源：文件句柄、锁、网络连接不靠垃圾回收，离开 with 块立刻归还。任何类实现 __enter__ / __exit__ 即可支持 with：

import time

class Timer:
    """with Timer(): 包住的代码块自动计时。"""
    def __enter__(self):
        self.start = time.perf_counter()
        return self                        # as 变量接住这个返回值

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.elapsed = time.perf_counter() - self.start
        print(f"耗时 {self.elapsed:.3f} 秒")
        return False                       # False：异常继续向外抛（True 则吞掉）

with Timer() as t:
    sum(range(10_000_000))
print(t.elapsed)

简单的场景用 contextlib.contextmanager 更省事，一个生成器搞定：

from contextlib import contextmanager
import time

@contextmanager
def timer(label: str):
    start = time.perf_counter()            # yield 之前 = __enter__
    try:
        yield                              # 暂停点：执行 with 体
    finally:
        print(f"{label}: {time.perf_counter() - start:.3f} 秒")  # 之后 = __exit__

with timer("求和"):
    sum(range(10_000_000))

Note · 打开文件必用 with

open(...) 不套 with 是新手最常见的资源泄漏来源；异常发生时没有 with 的话，close() 可能永远不会执行。

模块与包

模块是单个 .py 文件，包是带 __init__.py 的目录。import 时解释器按 sys.path 逐级搜索。典型工程布局：

myproject/
├── pyproject.toml
└── src/
    └── mypkg/
        ├── __init__.py      # 包入口：可在此暴露公共 API
        ├── core.py
        └── utils/
            ├── __init__.py
            └── text.py
# 绝对导入：从项目根写全路径，推荐，路径清晰
from mypkg.utils.text import slugify

# 相对导入：只在包内部使用
from .core import Engine             # 同级
from ..utils.text import slugify     # 上一级

if __name__ == "__main__"

让一个文件既能当模块被复用，又能当脚本直接跑：

def main() -> None:
    print("程序入口")

# 直接运行 python core.py 时 __name__ == "__main__"；
# 被别人 import 时 __name__ == "core"，main() 不会执行
if __name__ == "__main__":
    main()

涉及类型检查的导入，用 TYPE_CHECKING 保证运行时零开销，还能打破循环导入：

from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from mypkg.core import Engine    # 仅类型检查器读取，运行时不执行

def build(engine: "Engine") -> None: # 运行时用字符串前向引用
    engine.start()

类型注解进阶

基础注解（int、list[str]）之外，工程师最常用的是联合类型、协议与泛型：

from typing import Optional, Protocol, TypeVar

# Optional[X] 就是 "X | None"：找不到就返回 None
def find_user(uid: int) -> Optional[dict]:
    ...

# Python 3.10+ 用 | 写联合类型更直观
def parse(text: str | bytes) -> str:
    return text.decode() if isinstance(text, bytes) else text

# Protocol：鸭子类型的静态表达，"有这个方法就行"，不看继承血统
class Serializer(Protocol):
    def dump(self, obj: object) -> bytes: ...

def save(s: Serializer, obj: object) -> bytes:
    return s.dump(obj)               # 任何具备 dump 方法的对象都自动满足

# 泛型：在参数与返回值类型间建立关联
T = TypeVar("T")

def first(items: list[T]) -> T:
    """传入 list[int] 就推出 int，而非笼统的 object。"""
    return items[0]

Note · 注解不做运行时校验

类型注解默认不被运行时强制，交给 mypy / pyright 等静态检查工具。注解不影响程序对错，但公共 API 建议全部标注，等于免费的文档与回归检查。
