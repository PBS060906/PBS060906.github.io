线性代数

线性代数研究向量空间与线性映射，是理解深度学习数学表达的第一工具：模型的参数是矩阵，输入是向量，前向传播就是一串矩阵乘法。

向量与线性组合

  • 一组向量线性无关，指其中任何一个都不能由其余向量线性组合表示；向量空间的一组基是一组线性无关、且能张成全空间的向量；
  • 点积衡量两个向量的"对齐程度"：a · b = ∑i aibi = ‖a‖ ‖b‖ cos θ；
  • 常用范数：L1 范数 ‖a‖1 = ∑ |ai|（稀疏正则常用），L2 范数 ‖a‖2 = √∑ ai2（权重衰减的对象）。

余弦相似度只看方向不看长度，是文本向量检索的默认度量；欧氏距离对长度与方向都敏感：

cos θ = (a · b) / (‖a‖2 ‖b‖2)
运算几何意义
点积投影长度乘以被投影长度，夹角小于 90° 时为正
范数向量的"长度"
归一化除以 L2 范数，只保留方向

矩阵与变换

矩阵 A ∈ ℝm×n 本质是一个从 ℝn 到 ℝm 的线性映射。神经网络的一层就是一次矩阵乘法加激活：

h = σ(Ax + b)

乘法满足结合律 (AB)C = A(BC)，不满足交换律；AB 的几何意义是"先做 B 的变换，再做 A 的变换"；形状必须匹配：(m×n)(n×k) = m×k。

  • 单位矩阵 I：乘法下的"1"，A−1A = I；对角矩阵：各维度独立缩放；
  • 正交矩阵 Q（QTQ = I）：旋转 / 反射，不改变向量长度与夹角，数值计算中深受偏爱；
  • 对称矩阵（AT = A）：特征值全为实数，协方差矩阵就是它。

转置与求逆：(AB)T = BTAT，(AB)−1 = B−1A−1。同一向量在不同基下坐标不同：取新基对应的变换矩阵为 P，则新坐标 x′ = P−1x——特征分解正是寻找一组"最自然"的基，在新基下变换只是逐方向缩放。

核心概念速览

概念定义直觉
行列式det(A)变换对面积的缩放因子
秩rank(A)变换后空间的维度
特征值Av = λv变换下方向不变的向量
正定性xTAx > 0二次曲面的"碗形"保障

方阵可逆当且仅当满秩（det(A) ≠ 0）；det(A) = 0 意味着变换把空间"压扁"，信息不可逆地丢失。矩阵的迹等于特征值之和，行列式等于特征值之积，两者都是相似不变量。对称矩阵正定的判据：所有特征值大于 0，或所有顺序主子式大于 0。

核与像

线性映射 A 的像（列空间）是所有输出构成的空间，维度即 rank(A)；核（零空间）是被映成零向量的输入集合。核越"大"，映射丢失的信息越多——这正是秩亏意味着不可逆的原因。

线性方程组

Ax = b 有解当且仅当 rank(A) = rank([A | b])；解唯一当且仅当 A 满秩。数值上避免直接求逆，用消元（LU 分解）或迭代法求解；欠定方程（解不唯一）常加最小范数约束，超定方程（无精确解）退而求最小二乘解。

二次型与正定性

二次型 xTAx 把矩阵映射为标量；正定性保证它在 x ≠ 0 时恒为正，几何上是开口向上的"碗"——这也是 Hessian 判极值与牛顿法数值合理的根源。

特征值分解与 SVD

A = QΛQ−1  A = UΣVT
  • 特征分解要求方阵，可对角化要求存在 n 个线性无关的特征向量；SVD 对任意矩阵成立，是 PCA 的计算核心；
  • 奇异值的大小反映对应方向上的"信息量"，截断小奇异值即低秩压缩；对称矩阵可正交对角化 A = QΛQT；
  • 数值上求最大特征值常用幂迭代：反复做矩阵-向量乘法，方向收敛到主特征向量，是谱聚类等大规模谱方法的标配。
分解形式适用范围典型用途
LUA = LU方阵解线性方程组
QRA = QR任意矩阵最小二乘
特征分解A = QΛQ−1可对角化方阵谱分析、动力系统
SVDA = UΣVT任意矩阵PCA、低秩压缩

PCA 的流程用线性代数语言描述：

数据中心化→协方差矩阵→特征分解→取前 k 个特征向量

矩阵微积分一瞥

最小二乘的梯度是一切推导的模板：

∇w ‖Xw − y‖2 = 2XT(Xw − y)

令其为零即得正规方程 XTXw = XTy。

常用运算速查

import numpy as np

A = np.array([[1., 2.], [3., 4.]])
np.linalg.det(A)     # 行列式
np.linalg.eig(A)     # 特征值/特征向量
np.linalg.qr(A)      # QR 分解
U, S, Vt = np.linalg.svd(A)   # 奇异值分解

a = np.array([1., 2.])
b = np.array([3., 4.])
a @ b                # 点积 = 11
np.linalg.norm(a)    # L2 范数
cos = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))  # 余弦相似度

# 解线性方程组 Ax = b（优先于求逆）
x = np.linalg.solve(A, np.array([1., 2.]))

Note · 几何直觉优先

记公式前先想几何：矩阵 = 变换，行列式 = 面积缩放，特征向量 = 变换的"主轴"。

实践要点

  1. 见到矩阵乘法先核对形状：(m×n)(n×k) = m×k，深度学习里多数 shape 错误源于此；
  2. 判断一个矩阵能不能"压缩"：看奇异值衰减速度，衰减快即可做低秩近似；
  3. 权重衰减惩罚 L2 范数、L1 正则倾向稀疏解，理解范数即理解正则化；
  4. 余弦相似度对向量长度不敏感：先归一化再点积，二者等价；
  5. 数值上避免直接求逆 A−1b，优先用 np.linalg.solve 解线性方程组，更稳定；
  6. 高维数据的"维度灾难"与秩密切相关：有效信息往往藏在低秩子空间里，降维就是找这个子空间。
