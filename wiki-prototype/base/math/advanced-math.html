高等数学

高等数学为机器学习提供语言：导数描述变化，积分描述累积，级数描述极限。本页不求全面，只梳理与优化、概率、数值计算直接相关的核心工具。

极限与连续

极限是整个微积分的地基：导数是差商的极限，积分是和式的极限；函数在某点连续即"极限值等于函数值"。一个经典极限给出自然对数的底：

limn→∞ (1 + 1/n)n = e

求未定式极限（如 0/0 型）可用洛必达法则：分子分母分别求导后再取极限。

微分学

导数的几何意义

f′(x0) 是曲线在 x0 处切线的斜率，也是瞬时变化率；机器学习中的"梯度"就是导数在多元情形下的推广。常用基本导数与求导法则：

(xn)′ = nxn−1 (ex)′ = ex (ln x)′ = 1/x (sin x)′ = cos x
(fg)′ = f′g + fg′ (f/g)′ = (f′g − fg′) / g2

导数的符号给出单调性，二阶导数的符号给出凹凸性；拐点是凹凸性改变的点，也是二阶导数变号的点。

链式法则

复合函数求导是反向传播的数学基础：若 y = f(u)、u = g(x)，则

dy/dx = f′(g(x)) × g′(x)

神经网络层层嵌套，梯度正是靠链式法则从输出层逐层"回传"到输入层。

微分中值定理

罗尔定理与拉格朗日中值定理是"从导数性质推断函数性质"的桥梁：若 f 在 [a, b] 连续、在 (a, b) 可导，则存在 ξ 使得

f′(ξ) = (f(b) − f(a)) / (b − a)

泰勒公式

用多项式逼近函数，是优化与数值计算的基石：

f(x) = ∑n=0∞ [f(n)(x0)/n!] (x − x0)n

一阶泰勒展开 → 梯度下降；二阶泰勒展开 → 牛顿法：

xt+1 = xt − f′(xt) / f″(xt)

常用麦克劳林展开（x0 = 0 处的泰勒级数）：ex = ∑ xn/n!；ln(1+x) = ∑ (−1)n−1xn/n（−1 < x ≤ 1）。

积分学

  • 不定积分是导数的逆运算；定积分 ∫ab f(x) dx 表示曲线下面积，牛顿—莱布尼茨公式连接两者；
  • 两条常用技巧：换元法（变量替换）与分部积分；
  • 应用：面积、旋转体体积；概率密度函数在区间上的积分即事件概率，期望与方差都定义为积分。
∫ab f(x) dx = F(b) − F(a)  ∫ u dv = uv − ∫ v du
E[X] = ∫ x f(x) dx  Var(X) = ∫ (x − E[X])2 f(x) dx

级数与极限

最常用的是几何级数（等比数列求和）：

∑n=0∞ arn = a / (1 − r) (|r| < 1)

判断级数是否收敛是核心问题：等比级数与 p-级数 ∑ 1/np（p > 1 时收敛）是最常用的参照。它出现在折扣回报（强化学习）、指数衰减（学习率退火）等场景中；动量系数 β = 0.9 意味着历史梯度加权平均的"半衰期"约 7 步，同样源于等比求和。

多元函数

  • 偏导数：固定其他变量、只对某一个变量求导；全微分把各方向的微小变化累加；
  • 梯度 ∇f 指向函数值上升最快的方向，负梯度即最速下降方向；
  • Hessian 矩阵（二阶偏导构成的矩阵）刻画曲率，判断极值点性质；
  • 拉格朗日乘数法处理带约束优化，是 KKT 条件的前置知识：L(x, λ) = f(x) + λ g(x)。

极值的判定：一阶必要条件 ∇f(x*) = 0；二阶充分条件由 Hessian 的正定性给出——正定是极小值，负定是极大值，不定则需进一步讨论。

凸函数与优化

  • 凸集：集合内任意两点的连线仍在集合内；凸函数：f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)；
  • 凸函数的局部极小值就是全局极小值——这正是凸优化如此重要的原因；线性函数、各范数、ex、x2 都是凸的，非凸问题常被松弛成凸问题近似求解。

梯度下降的极简骨架：

for _ in range(num_steps):
    grad = compute_gradient(theta, X, y)
    theta = theta - lr * grad    # 沿负梯度走一小步

Tip · 与机器学习的联系

损失函数最小化 = 多元函数求极值；梯度下降 = 沿负梯度迭代；正则化 = 带约束优化。

实践要点

  1. 见到复合结构（如 log σ(x)）先想链式法则，逐层拆解再相乘；
  2. 手推一次"线性回归 + MSE"的梯度公式，是理解一切训练过程的最短路径；
  3. 学习率对应泰勒一阶近似的步长假设：步子太大会偏离近似成立的范围而发散；
  4. 遇到带约束问题（如最大间隔、概率单纯形）先检查拉格朗日 / KKT 是否适用；
  5. 对连乘的似然函数取对数，把连乘变连加，既好求导又避免数值下溢；
  6. 数值求导用中心差分 (f(x+h) − f(x−h)) / 2h，误差为 O(h2)，比单边差分更精确。
