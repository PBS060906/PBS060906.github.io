动态规划

动态规划 = 把原问题拆成重叠子问题，每个子问题只求解一次。适用条件：最优子结构 + 重叠子问题。

解题框架

  1. 定义状态：dp[i] 表示什么（最关键的一步）；
  2. 状态转移方程：dp[i] 如何由更小的子问题推出；
  3. 初始化与边界：递推的起点；
  4. 遍历顺序：保证计算 dp[i] 时依赖项已就绪；
  5. 空间优化：滚动数组压缩维度。

经典模型

线性 DP：最长上升子序列

dpi = maxj < i, aj < ai(dpj) + 1
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++)
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
}

贪心 + 二分可将复杂度优化到 O(n log n)。

背包 DP

模型转移方程
0-1 背包dp[j] = max(dp[j], dp[j-w]+v)，j 倒序
完全背包同上，j 正序
分组背包枚举每组"选哪一件"

区间 DP：石子合并

// dp[l][r] = 合并区间 [l, r] 的最小代价
for (int len = 2; len <= n; len++)
    for (int l = 0, r = l + len - 1; r < n; l++, r++) {
        dp[l][r] = INF;
        for (int k = l; k < r; k++)
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + sum(l, r));
    }

树形 DP：没有上司的舞会

树没有环，先把无根树转成有根树：任选一点作根，从根 DFS 确定父子关系，状态就能挂在“以 u 为根的子树”上。舞会问题：职员和直属上司不能同时参加，求最大快乐值之和。

// f[u][0/1]：u 不参加 / 参加时，其子树的最大快乐值
void dfs(int u) {
    f[u][1] = happy[u];
    for (int v : g[u]) {                  // v 是 u 的直接下属
        dfs(v);
        f[u][0] += max(f[v][0], f[v][1]); // 上司不来，下属随意
        f[u][1] += f[v][0];               // 上司来了，下属不能来
    }
}
// 答案：max(f[root][0], f[root][1])，root 为转有根树后的树根

状压 DP：旅行商问题 (TSP)

当 n ≤ 20 时，可以把集合压进二进制位：第 i 位为 1 表示第 i 个元素在集合中。TSP 要求经过每个城市恰好一次再回到起点，状压解法复杂度 O(n · 2n)。

// dp[S][u]：已访问集合为 S、当前在城市 u 的最小总路程
memset(dp, 0x3f, sizeof dp);  dp[1][0] = 0;   // 从 0 号城市出发
for (int S = 1; S < (1 << n); S++)
    for (int u = 0; u < n; u++)
        if (S >> u & 1)
            for (int v = 0; v < n; v++)
                if (!(S >> v & 1))
                    dp[S | 1 << v][v] = min(dp[S | 1 << v][v], dp[S][u] + w[u][v]);
// 答案：min(dp[(1 << n) - 1][u] + w[u][0])，枚举最后一个返回的城市

状压常用位运算技巧：

表达式含义
S >> i & 1判断第 i 个元素是否在集合中
S | 1 << i把第 i 个元素加入集合
S & ~(1 << i)把第 i 个元素移出集合
S & (S - 1)消去最低位的 1，可用来判断 2 的幂
(1 << n) - 1n 个元素的全集

常见线性模型一览

四个最常考的线性模型，把状态定义与转移放在一起对照记忆：

模型状态定义转移方程
LIS 最长上升子序列dp[i]：以 a[i] 结尾的 LIS 长度dp[i] = max(dp[j] + 1)，其中 j < i 且 a[j] < a[i]
LCS 最长公共子序列dp[i][j]：A 前 i 个与 B 前 j 个字符的 LCS 长度相等：dp[i-1][j-1] + 1；否则 max(dp[i-1][j], dp[i][j-1])
编辑距离dp[i][j]：A 前 i 个字符变成 B 前 j 个的最少操作数相等：dp[i-1][j-1]；否则 min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
最大子段和dp[i]：以 a[i] 结尾的最大子段和dp[i] = max(dp[i-1] + a[i], a[i])，答案取全局最大值

DP 与记忆化搜索

同一个状态设计，既能自底向上递推，也能自顶向下记忆化搜索。后者先写暴力递归、再加缓存，“要什么算什么”，往往更好想。以 LIS 为例，两种写法完全等价：

// 自顶向下：记忆化搜索
int dfs(int i) {
    int &res = memo[i];
    if (res) return res;                 // 已计算过，直接返回
    res = 1;
    for (int j = 0; j < i; j++)
        if (a[j] < a[i]) res = max(res, dfs(j) + 1);
    return res;
}

// 自底向上：递推（答案为 max(dp[0..n-1])）
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++)
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
}

如何选：转移“向前看”不直观、状态难以按序枚举时，记忆化搜索更自然；递归深度可能很大时改用递推，避免爆栈。

常见优化手段

  • 滚动数组：dp[i] 只依赖 dp[i-1] 时压掉一维；
  • 前缀和优化：转移是区间求和时预处理前缀；
  • 单调队列优化：滑动窗口最值，见 图论 之外的专题；
  • 矩阵快速幂：把线性递推（如斐波那契 f(n) = f(n-1) + f(n-2)）写成矩阵的幂，配合快速幂把 O(n) 加速到 O(log n)。

Tip

能对新手讲清楚"状态为什么这样定义、转移为什么正确"，才算真正掌握该模型。

Note

刷题按模型分类：集中一段时间专攻一个模型（如背包专题），吃透再换下一个；每题追求一题多解——先写暴力，再写标准 DP，最后尝试优化，比多刷十道新题收获更大。
